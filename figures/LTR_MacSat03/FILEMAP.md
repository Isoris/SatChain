## 2. One array = one file set (`figure/diagnostics/centromeres/{Mac,Gar}/`)

File names start with the chromosome and the array id, e.g. `LG05_Mac_SAT00380` (older files carry a `mac_` / `gar_` prefix). Mac = *C. macrocephalus*, Gar = *C. gariepinus*.

| suffix | what it is |
|---|---|
| `.fa` | the sequence: 5 kb flank (lowercase) + array (UPPERCASE) + 5 kb flank; use the flanks for locus-specific primers |
| `.gb` | the same sequence as GenBank with features (array, runs, flanks, monomers, RTE hits, gaps) |
| `_igv.bed` | IGV track in genome coordinates |
| `_rlvl1_context.png` | the array to scale + class composition per block + its place on the ideograms of both genomes + non-specific amplification |
| `_chromosome.png` | the chromosome with every marker on it |
| `_marker_matrix.png` / `_marker_matrix_empty.png` | the marker table of this chromosome, filled and blank to fill by hand |
| `_divmap.png` / `_divmap_vs_centromeres.png` | identity map of the array and its flanks / identity to all other centromeres |
| `_rlvl2_stack.png` | blocks aligned, composition domains |
| `_rlvl3_linear.png` | every monomer copy along the array |
| `_rlvl3_topology.png` | transition graph between monomer classes |
| `_classes.tsv` | the monomer classes of the array |

## 4. Naming

- Families have two names: the pipeline id (`GarSat04`, `MacSat06` ...) and the manuscript name of v4.6 (`CgaSat001-216`, `CmaSat002-214`: Cga = *C. gariepinus*, Cma = *C. macrocephalus*, the number after the dash = unit length in bp).
- Chromosomes: `LG01` ... ; in tables `G01` = *C. gariepinus* LG01, `M01` = *C. macrocephalus* LG01.
- Position classes: C = centromeric, I = interstitial, T = terminal (within 5 % of a chromosome end).
- `rlvl1 / rlvl2 / rlvl3` = resolution level 1 (what), 2 (how arranged), 3 (which exactly).
