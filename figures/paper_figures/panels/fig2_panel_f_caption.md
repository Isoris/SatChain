# Figure 2f caption stub (100 x 46 mm)

**f | One interrupted MacSat03 array on C. macrocephalus LG04, drawn to scale.** Top: the whole array (28 satellite runs, 27 interruptions, 371 kb; 132 kb of satellite in runs, 239 kb of interruptions) inside the LG04 centromere interval (pale grey, 27.70-28.13 Mb); runs are drawn copy by copy (one cell = one monomer copy, coloured by monomer class; grey = partial copy), gold arrows are RTE fragments in the interruptions (arrow = RTE 5'->3'; all 29 point along the chromosome), bars below are the spacer types A, B, C. Bracket = region enlarged below. Bottom: four consecutive units (units 7-10; types A, C, C, B); unit = one satellite block + the spacer that follows it; the dark red tick is the 245-bp ins that defines type A.

**Evidence level.** Runs, copies, classes and RTE fragments are L1 (sequence). The spacer-type reading is **L2** (structural inference): A and C are supported spacer types, B is the remainder; it is one array (LG04) and not a general rule.

**Spacer type definitions (from the spacer analysis, split/spacer_types_msa and figure/diagnostics/spacer_types_msa.py, spacer_int_view.py).** Reference-free MAFFT comparison of the 26 typed interruptions (interruption 1 is a truncated 1.3-kb end piece and is not typed).
- A: interruption carries the 245-bp ins (11 interruptions, 14 ins copies; interruption 4 has four tandem copies). Exact-support variants of the ins carriers as a group: 25 (MAFFT auto) / 37 (--localpair); cluster present in 94.7 % / 99.7 % of bootstrap resamples.
- C: no ins, and 12 variants of its own (exact-support split = the 5 members; 7 after masking microsatellites) (5 interruptions: 8, 9, 13, 15, 21); bootstrap 89.0 % / 95.7 %.
- B: remainder, no ins and no variant of its own (10 interruptions: 2, 10, 11, 12, 14, 16, 17, 18, 22, 23); 0 exact-support variants; bootstrap 88.7 % / 95.3 %. B is residual by construction, it is not shown to be a type of its own (B without interruption 2 is not a supported cluster: 14 % / 22 %).

**Sweeps (all in fig2_panel_f_numbers.tsv, rows `sweep_*`).**
- A (ins carrier), re-tested independently: share of the ins 15-mers found (both strands) in each interruption: A members 0.87-1.00, every other interruption 0.00. Thresholds 0.1, 0.3, 0.5, 0.7 give exactly the 11 A interruptions; 0.9 drops two diverged copies (9 of 11). So the A / non-A call does not depend on the threshold unless it is set above ~0.87.
- B vs C, re-tested without the labels: unsupervised average-linkage cut into two clusters of the 15 no-ins interruptions on alignment substitution columns, minor-allele count >= 2 / 3 / 4 (42 / 36 / 30 columns, MAFFT auto; 41 / 35 / 30, --localpair): all six settings recover exactly the C set (5 + 10).
- Monomer class "partial copy" (truncated, or identity < cutoff to its class): cutoff 70 / 80 / 90 % changes 0 / 0 / 1 of 599 copies (29 / 29 / 30 partial copies). All 29 are truncated copies.
- RTE fragments: minimum HSP length 150 / 500 / 1000 / 2000 bp gives 29 / 29 / 29 / 29 arrows in 26 interruptions (no threshold effect; the longest-fragment lengths of 2-3 kb all pass).
- Display choices (not results): overview = whole centromere interval at 0.222 mm/kb; zoom = units 7-10 at 1.54 mm/kb (the first window containing types A, C and B).

**Caveats.** Unit length varies 6.7-25.9 kb (median 13.0 kb; interruption 4 has four tandem RTE-ins pairs). The 191-bp satellite piece in interruptions 20 and 24 is not drawn. Classes C04, C06-C09 have 17-27 copies in the runs (below the 30-copy k-mer test minimum); an exploratory test with >= 10 copies finds all 36 class pairs supported. The class assignment partly follows the identity to consensus (circular), so the class colours show structure, not independent evidence.
